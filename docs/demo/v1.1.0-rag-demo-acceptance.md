MySQL is authoritative, Qdrant is rebuildable, and only current `VERIFIED`
papers with normalized DOIs and matching reconstructed Segments become answer
evidence. CitationGuard does not establish semantic entailment or full-text

2. Formal Recall@1/3/5, Hit@5, and MRR are measured from the reviewed labels.
3. The `maxEvidence=5` boundary is exercised with at least five admitted
   ABSTRACT evidence items, or its unmeasurability is explicitly accepted.
4. Independent human review remains optional follow-up; the current formal
   labels are explicitly marked as Codex-reviewed.
5. Unrelated worktree files are removed by their owner and the release worktree
   is clean.
6. The user separately authorizes pushing `main` and creating the tag.
