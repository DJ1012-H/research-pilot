# v1.0.0-demo acceptance

Date: 2026-08-06
Decision: **PASS**

## Accepted scope

This release closes the trustworthy literature-search main plan through
2026-08-10. It includes the synchronous API, trusted search-plan validation,
bounded Agent execution, OpenAlex retrieval, Crossref verification, formal
paper admission, citation-checked abstract review, optional MySQL persistence,
optional Redis caching, observability, startup scripts, and reproducible
acceptance evidence.

Qdrant, embeddings, PDF ingestion, and RAG business code are excluded. They
remain a separate post-2026-08-10 extension and are not required for this
release decision.

## Approved closeout corrections

- The public result contract is 1–15 papers and defaults to 5. The request DTO,
  Java domain invariant, model-output schema, and runtime configuration enforce
  the same ceiling.
- Flyway V1 remains immutable. Its historical `1..50` storage envelope is
  wider than the release application contract and cannot admit a plan that
  failed Java validation.
- The controlled Agent permits 10 business actions, correcting the historical
  plan's stale estimate of 8. The bound covers an initial plan, two
  four-action retrieval rounds, and one controlled refinement. Terminal
  `COMPLETE` or `TERMINATE` records the outcome without consuming another
  business action.
- Retrieval remains bounded to two OpenAlex rounds and one refinement.
  Crossref performs at most `min(requested target, 10)` new lookups per round.
